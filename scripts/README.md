# Poster and QR asset maintenance

Run from the repository root with Python and review the command help for the specific asset. Check local PDF/image tools before refreshing the preview. The site’s root README explains deployment and print use.

## Script and notebook guide

| File | Purpose |
| --- | --- |
| [`generate_qr.py`](generate_qr.py) | Generates QR code assets for the configured contact-card URL and print/web formats. |
| [`update_poster.py`](update_poster.py) | Updates the conference poster and prepares its preview image for the static site. |
| [`verify_qr.py`](verify_qr.py) | Checks a generated QR image and inspects encoded data for verification. |
